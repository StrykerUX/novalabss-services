# NovaLabs - Design as a Service

## 🎯 Concepto General
**NovaLabs** es una plataforma de suscripción para servicios de diseño web automatizado, enfocada en el mercado mexicano/latinoamericano. Ofrece creación rápida de sitios web estáticos (landings y sitios nivel 1) con automatización de procesos y UX centralizada.

## 🎨 Branding
- **Marca**: NovaLabs
- **Dominio**: novalabss.com
- **Estilo**: Vercel-inspired (limpio, moderno, tech)
- **Tipografía**: 
  - **Títulos (H1-H6)**: Space Grotesk
  - **Texto general**: Poppins
- **Temática**: Espacial/Tech (Nova = estrella que explota)

## 🚀 Propuesta de Valor
- **Automatización con Claude Code**: Desarrollo acelerado (3-4h por proyecto)
- **Rapidez**: Entrega garantizada en 72-96 horas
- **Pricing Accesible**: Precios competitivos para PyMEs mexicanas
- **Todo Centralizado**: Analytics propio, comunicación y gestión en una plataforma

## 📋 FEATURES PRINCIPALES

### 1. Landing Page Optimizada
- UX/UI atractiva con ingeniería social sutil
- Trucos psicológicos para generar necesidad sin ser invasivo
- Call-to-actions estratégicos
- Pricing transparente en pesos mexicanos

### 2. Sistema de Autenticación
- Registro con datos mínimos + verificación obligatoria
- 2FA opcional para seguridad
- Proceso sin fricciones

### 3. Sistema de Suscripciones (2 Planes)
#### Planes:
- **Rocket**: $999 MXN bimestral
  - 1 landing page <72h
  - 2 créditos para cambios
  
- **Galaxy**: $1,799 MXN bimestral  
  - Sitio 3-5 páginas <96h
  - 2 créditos para cambios

#### Incluido en Ambos:
- SEO básico (meta tags, sitemap)
- Analytics propio (básico)
- Hosting con dominio temporal
- Modalidad anual con descuento

### 4. Onboarding Inteligente (10-20 min)
Recopilación de información clave para el proyecto:
- Datos del usuario y negocio
- Branding y preferencias visuales  
- Objetivos y funcionalidades específicas
- Preguntas abiertas para detalles

### 5. Dashboard de Usuario
- **Proyectos**: Estado, URLs.
- **Analytics Propio**: Métricas básicas del sitio (pageviews, visitors, bounce rate)
- **Suscripciones**: Gestión de planes y pagos
- **Créditos**: Sistema de puntos para cambios menores
- **Configuración**: Datos personales, 2FA

### 6. Sistema de Comunicación
- **Fase 1**: WhatsApp con mensajes predeterminados por proyecto
- **Fase 2**: Chat interno integrado en la plataforma
- **Objetivo**: Centralizar comunicación sin salir del entorno

### 7. Sistema de Créditos/Puntos
Servicios canjeables por puntos:
- **1 punto**: Popup personalizado, Quick Links (Linktree), Formulario simple
- **2 puntos**: Email personalizado, Modificación de sección

### 8. Estrategias de Retención
- **Gamificación sutil**: Niveles discretos (Starter → Pro → Elite)
- **Fricción en cancelación**: Pausas, downgrades, ofertas personalizadas
- **Beneficios progresivos**: Dominio gratis al segundo pago
- **Ingeniería social**: Progress tracking, social proof ambiental

## 🛠 STACK TECNOLÓGICO

### Core Stack
- **Next.js 14** + TypeScript
- **Tailwind CSS** + Framer Motion
- **Prisma** + PostgreSQL
- **NextAuth.js** + Stripe
- **Dokploy** hosting VPS

### Características Técnicas
- **Sitios estáticos**: Sin BD en sitios cliente (nivel 1)
- **Analytics propio**: Tracking ligero <5KB
- **Claude Code**: Acelerar desarrollo 3-4h por proyecto
